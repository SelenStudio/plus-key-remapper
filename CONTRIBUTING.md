# Contributing

Thank you for your interest in contributing! Here is how to do it:

## How to contribute

1. **Fork** this repository using the Fork button on GitHub
2. **Clone** your fork locally
   ```
   git clone https://github.com/YOUR_USERNAME/REPO_NAME.git
   ```
3. **Create a branch** for your change
   ```
   git checkout -b fix/your-description
   ```
4. **Make your changes** and commit them with a clear message
   ```
   git commit -m "fix: describe what you changed and why"
   ```
5. **Push** to your fork
   ```
   git push origin fix/your-description
   ```
6. **Open a Pull Request** against the `main` branch of this repository

## Guidelines

- One change per PR - keep it focused
- Describe what your PR does and why in the PR description
- Test on a physical device before submitting
- Follow the existing code style

## Review

All PRs are reviewed by the maintainer before merging. Nothing is merged without approval. Please be patient - reviews may take a few days.
